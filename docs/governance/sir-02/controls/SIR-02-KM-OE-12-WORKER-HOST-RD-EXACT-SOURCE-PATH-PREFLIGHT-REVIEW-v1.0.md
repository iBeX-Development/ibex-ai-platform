Worker lifecycle is otherwise separate (`supervisor.mjs:52,105,165–168`). Evidence write failure can interrupt closure/finalization. No post-closure accepted append appears in `receive()`, but the full authoritative integrity path is not complete.

**Numeric-bound path: GAP.** `config.json:19–26` contains exactly 8,000/10,000/2,000/2,000/500/5,000/45,000 ms. Source consumes these at `supervisor.mjs:77–90,116–118,132–141,148–168`, `controller.mjs:28–30,66–73,103–108,130–132`, and `protocol.mjs:43–53`. Yet startup starts after `spawn` and omits READY; closure starts its clock inside `close`; ownership `durationMs` measures query duration rather than age immediately before action; the disposal timer starts after cooperative EOF and resets in finally; total-run `setTimeout` does not bound a blocked event loop. The 11 s WH-02/05 delays are literals (`worker.ps1:53,65`). Expiry cannot be shown to meet every reviewed start/end contract.

**Disposal/cleanup: GAP with honest STOP.** Closure, cutoff and result revocation (`protocol.mjs:43–49`, `controller.mjs:64–70`) are distinct from worker exit. `supervisor.mjs:116–142,149–168` uses only fresh-query-gated cooperative EOF and bounded observation, with no prohibited destructive fallback. **Evidence/failure integrity: GAP.** Synthetic worker self-query avoids real tenant/Core data; source logs digests/categories rather than raw command lines or chain-of-thought (`worker.ps1:55–71`, `supervisor.mjs:101–104`).
