## Ownership and disposal review boundary

The prepared source checks PID, image, parent PID, native and CIM creation time, Node command-line run token/probe path, and creation/assignment references in a hash-pinned receipt (P:47-71, P:134-151, P:186-210). It retains a read-only process handle (N:26-90). It does not launch, signal, terminate, or otherwise affect a target process. It checks native identity immediately before and after each CIM query. The receipt SHA-256 is supplied with the input; **that pairing alone does not independently authenticate who created or approved the receipt**. This is a source-review issue, not proof of ownership.

The outer `finally` follows the approved ten-step order with steps 3-5 recorded N/A because this source creates and controls no child, Job, or CIM session. It stops new queries, records the primary result, checks pipeline disposition, closes only opened read-only handles, removes only its scratch file/empty directory, verifies resource state, then emits final evidence. An unresolved asynchronous CIM pipeline prevents a PASS. The source-level reviewer must still determine whether the bounded Windows PowerShell 5.1 cancellation path safely proves quiescence on every provider state.
