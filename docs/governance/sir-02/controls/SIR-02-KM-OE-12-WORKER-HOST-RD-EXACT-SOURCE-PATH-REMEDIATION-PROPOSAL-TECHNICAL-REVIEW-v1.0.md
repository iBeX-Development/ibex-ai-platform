## 4. Required proposal revision before owner change-control review

1. **Attempt consumption and entry-path order:** require a trusted, atomic, durable one-use attempt claim before *any* execution-relevant side effect, including audit-file creation or process creation under the selected entry path. Map the first side effect in Controller, Supervisor, direct Worker and direct Helper entry paths. Bind consumed attempt to exact authorization, package/config bytes, run/generation, case and evidence destination. A crash, exception or preflight failure after consumption must remain a consumed failed attempt; no silent retry or reuse. The owner must approve the independent attempt ledger/anchor.
2. **Malformed/partial zero-mutation rule:** require schema validation before `AuthorityFence` changes sequence, accepted set/count or terminal eligibility. For every malformed/null/partial/provider-failure frame, authoritative state remains byte-identical; retain a separately classified rejection/error record. Audit failure may invalidate the candidate but cannot backdate acceptance.
3. **Helper lifetime bound:** assign an explicit numeric maximum and endpoints for a timed-out identity observer's entire lifetime through exit or qualifying approved isolation, including the timeout/exception/finally paths. If no non-destructive finite bound can be justified, preserve STOP and require a separate owner boundary decision.
4. **Evidence failure versus terminal immutability:** state that an immutable terminal value is not rewritten because audit/sidecar persistence later fails; separately mark candidate evidence/acceptance invalid and retain the failure through an independently trusted sink. If that sink is unavailable, preserve an explicit unresolved STOP rather than claiming PASS.
5. **Outer entry/import path:** specify how a future trusted launcher verifies authorization and runnable bytes before any side-effecting import or direct process entry, and how direct Worker/Helper invocation is rejected. Do not assume an in-module `executionGate()` runs before static imports.

The independent authorization/evidence anchor, receipt producer and complete membership method, attempt ledger, and bounded non-destructive worker/helper isolation remain **separate owner/change-control decisions**. This review selects none. A later corrected proposal must be exact-byte reviewed again before any source-change authorization; any new source must undergo its own preflight, safety review and separate R&D execution authorization.
