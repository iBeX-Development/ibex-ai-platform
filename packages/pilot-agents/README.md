# Pilot agents

Phase 8 provides versioned, evaluation-stage configuration and a fail-closed response guard for the General iBeX, Maintenance, Asset, and Warehouse agents.

Live Core Tool/API bindings and production agent selection remain disabled until exact Core contracts, service identities, authentication details, schemas, permission mappings, and entitlement mappings are approved. The runtime accepts no caller-supplied answer, evidence, citation, provenance, or execution mode. Server-side grounding uses the Phase 5 Tool and Phase 6 RAG contracts, verifies context and RAG integrity, emits normalized Phase 7 audit evidence, and abstains instead of inventing operational facts.

This package does not implement Human Approval Runtime, authoritative writes, autonomous multi-agent execution, PM/PdM logic, production rollout, or provider-specific calls.
