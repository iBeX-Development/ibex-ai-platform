# Pilot agents

Phase 8 provides versioned, evaluation-stage configuration and a fail-closed response guard for the General iBeX, Maintenance, Asset, and Warehouse agents.

Live Core Tool/API bindings remain disabled until exact Core contracts, service identities, authentication details, schemas, and permission mappings are approved. The runtime accepts only trusted server context, enforces per-intent permissions and allowlists, requires evidence and citations, and abstains instead of inventing operational facts.

This package does not implement Human Approval Runtime, authoritative writes, autonomous multi-agent execution, PM/PdM logic, production rollout, or provider-specific calls.
